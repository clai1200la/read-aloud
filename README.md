# Read Aloud

Paste an X post or article link and hear it read aloud in a natural, free AI voice.

- **AI voice:** [Kokoro](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX), an open-source voice model that runs entirely in your browser. No API key, no account. First use downloads ~90 MB, then it's cached.
- **Device voice:** your phone or computer's built-in voices. Instant fallback.
- **X posts** via the free FxTwitter API. **Articles** via Jina Reader.

Tip: open `?url=<link>` to load a link directly.
